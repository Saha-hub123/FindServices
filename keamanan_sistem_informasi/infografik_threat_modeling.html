Ringkasan Sistem & Profil Arsitektur

Karakteristik target aplikasi, profil aktor, tumpukan teknologi, dan ruang lingkup audit

Identitas & Tujuan Platform

FindServices adalah platform marketplace berbasis web yang memfasilitasi pencarian dan pemesanan penyedia jasa lokal (tukang/teknisi) terdekat.

Fitur Utama: Haversine GPS, Chat Socket, Midtrans
Basis Jarak: Radius Koordinat Latitude / Longitude
Tipe Transaksi: Escrow Digital (Snap) & Tunai (COD)

Stack Teknologi Terverifikasi

Backend Framework Laravel 12 (PHP 8.3)
Frontend Stack Vue 3 + Inertia.js
Database Utama MySQL 8.0 Engine
Real-time Engine Laravel Reverb :8080
Payment Gateway Midtrans Snap API
Ingress / Tunnel Cloudflare Tunnel

Aktor Pengguna & Batasan Ruang Lingkup

CUSTOMER Pencari jasa, membuat booking, bayar, rating review.
PROVIDER Penyedia jasa, verifikasi order, negosiasi harga, eksekusi.
ADMIN Pengelola master data kategori, resolusi dispute & audit.
Ruang Lingkup: Static code review, audit konfigurasi environment (.env), dan threat modeling non-destruktif.

T-01 (CVE-2023-28438)
TE

Penyerang yang terautentikasi memanipulasi parameter order_id pada endpoint status booking di BookingController tanpa verifikasi kepemilikan akun, sehingga dapat mengubah status pesanan milik pengguna lain secara sepihak.

CRITICAL
Skor: 40/50
Damage 8
Reprod 9
Exploit 8
Affected 8
Discov 7
Bukti Kode Sumber:
BookingController.php baris 228–232: pengecekan hak akses kepemilikan auth()->id() dikomentari sehingga siapa pun dapat mengubah status booking.
Alasan Skoring: Damage 8: penyerang dapat membatalkan atau mengubah sepihak status transaksi pengguna lain; Reproducibility 9: serangan sangat mudah diulang dengan mengganti parameter booking ID; Exploitability 8: dapat dieksekusi dengan request HTTP PATCH sederhana; Affected Users 8: berdampak pada seluruh pengguna aktif sistem; Discoverability 7: celah otorisasi mudah ditemukan melalui inspeksi endpoint API.
Rekomendasi Tindakan Mitigasi:

Aktifkan kembali validasi hak akses kepemilikan if (auth()->id() !== $booking->provider_id && auth()->id() !== $booking->customer_id) abort(403); dan gunakan Laravel Authorization Policy.

D

CRITICAL
Skor: 40/50
Damage 7
Reprod 9
Exploit 9

Discov 7
Bukti Kode Sumber:
routes/api.php baris 15–52: route POST /test-latency memicu TestLatency::dispatch tanpa middleware auth maupun rate limiting.
Alasan Skoring: Damage 7: melumpuhkan fitur chat dan notifikasi real-time bagi seluruh pengguna; Reproducibility 9: sangat mudah diulang menggunakan script load testing; Exploitability 9: endpoint terbuka untuk publik tanpa autentikasi; Affected Users 8: memengaruhi seluruh pengguna yang mengandalkan real-time event; Discoverability 7: endpoint /api/test-latency tercantum jelas pada routes/api.php.
Rekomendasi Tindakan Mitigasi:

Saran & Pendapat Ahli Keamanan (Action Roadmap)

Rencana mitigasi bertahap untuk tim pengembang dan pengambil keputusan

FASE 1: SEGERA (0 - 48 JAM) Hotfix Kritis

Penutupan Celah BOLA & DoS Socket

  • Aktifkan auth check di T-01: Un-comment pengecekan kepemilikan di BookingController.php:230.
  • Proteksi Endpoint T-02: Hapus atau bungkus route /api/test-latency dengan auth:sanctum & throttle rate limiter.
  • Validasi MIDTRANS_SERVER_KEY (T-03): Wajibkan kunci server Midtrans tidak boleh null atau kosong di production.
FASE 2: JANGKA MENENGAH (1-2 MINGGU) Hardening Kode

Pengerasan Konfigurasi & Input Sanitization

  • Enkripsi Sesi (T-08): Ubah SESSION_ENCRYPT=true di .env dan pasang flag HttpOnly, Secure.
  • Mass Assignment Fix (T-06): Keluarkan properti 'role' dari array $fillable model User.
  • Sanitasi XSS & Upload (T-05 & T-07): Terapkan strip_tags pada komentar review dan validasi magic-bytes untuk upload gambar.
FASE 3: STRATEGIS (1 BULAN) Arsitektur Tangguh

Infrastruktur & Otomasi DevSecOps

  • Spatial Caching (T-04): Tambahkan Redis caching untuk query rumus Haversine geolokasi katalog.
  • WAF & Rate Limiting: Konfigurasikan Cloudflare WAF rule untuk inspeksi webhook payload dan mitigasi DDoS.
  • Automated Security Scanning: Integrasikan SAST (SonarQube / PHPStan Security) pada CI/CD pipeline GitHub Actions.
